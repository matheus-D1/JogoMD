# 🕹️ BOX BIRD 2.5
### Desenvolvido na Unity Engine

> Um jogo de pulos rápido em 2.5D onde você controla um pássaro quadrado e precisa desviar de obstáculos!

---

## 🛠️ Info Técnica & Equipe

* **Engine:** Unity (LTS 2022+)
* **Linguagem:** C#
* **Plataforma:** PC / Windows
* **Equipe:**    * **[Matheus Davi]** 

---


## 📥 Como Rodar

1. **Clone o repositório:** `https://github.com/usuario/box-bird-2-5.git`
2. **Abra no Unity:** Use o Unity Hub para abrir a pasta do projeto.
3. **Execute a Cena:** Abra a cena principal em `Assets/Scenes/MainScene.unity` e dê Play.
